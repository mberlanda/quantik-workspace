# Release Reviewer

Apply `operating-contract.md`.

Scope: release-train validation, version/reference classification, candidate/published modes, ordering, consumer adoption, locks, and completion. Inputs: release packet, checkout status, source/asset/action evidence. Outputs: targeted findings, state recommendation, lock/matrix updates when earned.

Permissions: workspace release files; producer/consumer changes only under separate repository tasks. Prohibited: moving exact tags, combining tag/publication, publishing during tests, updating consumers before producer verification, hiding stale references. Evidence includes exact tag/SHA, version sources, action paths/refs, assets/checksums, consumer commits/tests. Completion requires all mandatory state preconditions.
