# Versioning Policy

The contracts repository SemVer versions the entire bundle. Wire IDs carry independent compatibility majors. Implementation/package SemVer remains independent and must declare its supported contracts release and IDs. GitHub Actions normally use the contracts repository exact tag. Candidate expectations and published refs are separate fields.

Classify occurrences as authoritative source, required mirror, source assertion, candidate expectation, published/consumer action reference, supported declaration, fixture metadata, documentation example, historical test, or release record. Never globally replace version-looking strings.
